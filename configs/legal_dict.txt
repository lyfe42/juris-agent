# 法律领域词典（jieba 用户词典格式：词 [词频] [词性]）。
#
# ⚠️ 这份词典被**实测教训**改过一次，留下了痕迹，别删这段说明：
#
# 第一版收了 50 多个词，包括「经济补偿金」「经济补偿」「赔偿金」这类短词。
# 实测结果是 **Recall@5 从 0.571 掉到 0.476**——加词典反而变差。查下来的机制是
# **过度合并切断了部分匹配**：
#
#   查询「经济补偿金是怎么算的」在无词典时切成 `经济 / 补偿金`，
#   其中 `经济` 命中了第四十七条里的「经济补偿」→ 排名第 8；
#   加了词典后 `经济补偿金` 被合并成一整词，而第四十七条写的是「经济补偿」——
#   一词之差，直接变成**完全没命中**。
#
# 所以这里的收录标准收窄成一条：**只收 jieba 默认切法确实会把语义切散的长词**
# （如「无固定期限劳动合同」）。短词的同义问题（经济补偿金 vs 经济补偿）
# 属于**查询侧**的活，交给 F9 查询改写的同义词表去做——
# 文档侧强制合并是错的工具。
#
# 词频给 3~5：太高会盖过 jieba 的统计分词，把不该连的词也连起来。
